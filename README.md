## 提交 Session 和 Cookie 前，先做这份检查

这是 ChatGPT Pro 5x 代充最需要认真考虑的部分。

### 核对平台是否使用加密传输

确认页面是否使用 HTTPS，并阅读平台隐私政策中关于 Session、Cookie、支付链接和账号标识的说明。不要因为网站有锁形图标，就默认所有凭证都会被妥善处理。HTTPS 只能说明传输过程经过加密，不能自动说明平台内部保存和访问权限没有问题。

### 看清凭证保存多久

重点关注以下问题：

- 凭证是否只用于本次订阅。
- 订单完成后是否自动删除。
- 用户能否主动申请删除。
- 售后争议期间是否会继续保存。
- 哪些系统或员工可以访问。
- 如果平台停止运营，凭证如何处理。

一些公开资料显示，WildAI 的服务流程可能涉及 Session Token、Cookie、支付链接或其他订阅凭证。不同产品的要求并不完全相同，所以不要只看首页的宣传说明，还要查看具体套餐页面和隐私政策。

### 开通完成后检查账号

订阅成功后，建议完成以下操作：

1. 在 ChatGPT 账户中确认套餐名称和到期时间。
2. 查看是否出现陌生的活跃会话。
3. 检查账号邮箱、手机号和安全设置。
4. 如果怀疑凭证已经暴露，立即退出其他会话并修改密码。
5. 重新启用多因素验证。
6. 保存订单截图、付款记录和售后规则。

不要把账号密码、邮箱密码、短信验证码和银行卡完整信息发送给第三方。WildAI 的公开教程主要要求 Session 或 Cookie，但具体订单流程可能变化，任何额外信息都应该先确认用途。
